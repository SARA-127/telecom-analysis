Análisis de clientes de ConnectaTel
1. Objetivo del proyecto

Analizar el perfil y los patrones de uso de los clientes de ConnectaTel para identificar segmentos de usuarios, evaluar la calidad de los datos, detectar valores atípicos y formular recomendaciones de negocio que contribuyan a mejorar la toma de decisiones.
2. Contexto del proyecto

ConnectaTel busca comprender mejor el comportamiento de sus clientes a partir de variables demográficas y de uso de sus servicios.
3. Datasets utilizados

El proyecto utiliza información de los perfiles de los clientes y de su actividad.

Las principales variables analizadas son:

age: edad del cliente.

plan: plan contratado por el cliente, como Básico o Premium.

cant_mensajes: cantidad de mensajes enviados.

cant_llamadas: cantidad de llamadas realizadas.

cant_minutos_llamada: cantidad de minutos utilizados en llamadas.

4. Herramientas utilizadas

Python: lenguaje de programación utilizado para el análisis.

pandas: manipulación, limpieza y análisis de los datos.

NumPy: operaciones numéricas, si se utiliza en el notebook.

Matplotlib y Seaborn: creación de histogramas, diagramas de caja y otras visualizaciones.

Jupyter Notebook: entorno para ejecutar el código y documentar los resultados.

5. Metodología

El análisis se desarrolló mediante las siguientes etapas:

Exploración inicial: revisión de la estructura de los DataFrames, las columnas, los tipos de datos y la cantidad de registros.

Evaluación de calidad: identificación de valores ausentes, revisión de tipos de datos y comprobación de posibles inconsistencias.
